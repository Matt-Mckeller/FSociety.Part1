# Brand & Design System

**Purpose**: Brand identity, design data, and content examples that apply across ALL businesses.

## What's In Here

This folder contains design, brand, and content information that is shared across all Expanse businesses (4eye, 1game, Expanse Work, 4up, Expanse Services).

### Files
- `PURPOSE_AND_GOALS.md` - Core purpose and goals across businesses
- `MATTHEW_DATA.md` - Personal brand and voice data
- `PURPOSE_DATA.md` - Purpose-driven content and messaging
- `DESIGN_DATA.md` - Design principles, patterns, aesthetics
- `SOFTWARE_DATA.md` - Software approach and principles
- `README_UPDATE_SUMMARY.md` - Update history

### Examples Folder
Contains practical examples of:
- Design patterns and animations (`examples/design/`)
- Theme weights and variations (`examples/THEME_WEIGHTS_EXAMPLES.md`)
- Content writing examples for AI (`examples/FEW_SHOT_CONTENT_EXAMPLES.md`)

## How This Is Used

This data is referenced when:
- Creating content for any business
- Designing user interfaces
- Establishing brand voice
- Training AI on brand guidelines
- Ensuring consistency across businesses
