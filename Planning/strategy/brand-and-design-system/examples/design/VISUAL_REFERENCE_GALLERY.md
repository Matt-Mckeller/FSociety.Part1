## Design Anti-Patterns

### Avoid
- Cluttered, busy layouts
- Overly literal representations
- Inconsistent geometric language
- Static, non-interactive experiences (where interaction would add value)
- Conflicting visual themes without purpose

### When Breaking Rules
If a design doesn't match preferences but serves its purpose exceptionally well:
- **Flag for review** - explain the value it brings
- **Consider context** - does it fit the specific use case?
- **Evaluate tradeoffs** - is the benefit worth the theme deviation?

**Don't limit creativity** - these are preferences to guide, not restrict.

## Usage Guidelines

### For Designers
1. **Start with themes** - which theme(s) does this asset need to convey?
2. **Select symbols** - choose core symbols or related variations
3. **Apply style** - geometric, minimalistic, modern
4. **Add interactivity** - where appropriate for engagement
5. **Vary execution** - fresh interpretations prevent repetition

### For Content Creators
1. **Reference these visuals** when briefing designers
2. **Use symbol language** in copy where it enhances meaning
3. **Consider motion** - could animation strengthen the message?
4. **Think gamification** - how could this be interactive?

### For AI Systems
1. **Extract theme tags** from visual examples
2. **Match visual concepts** to copy themes for consistency
3. **Suggest symbol combinations** that haven't been overused
4. **Recommend fresh variations** on established patterns
