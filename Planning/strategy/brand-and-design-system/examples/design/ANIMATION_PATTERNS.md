## Technical Specifications

### Lottie Animation Guidelines

**File optimization:**
- Keep file sizes reasonable (<200KB ideal)
- Use efficient shapes over bitmaps where possible
- Optimize keyframes and easing
- Test performance on target devices

**Compatibility:**
- Ensure web and mobile compatibility
- Test across browsers/platforms
- Provide fallback states
- Consider reduced-motion preferences

### Timing & Easing

**Duration guidelines:**
- Micro-interactions: 100-300ms
- Feedback animations: 300-500ms
- Reveal animations: 500-800ms
- Storytelling sequences: 1-3 seconds
- Background/ambient: varies, often looped

**Easing preferences:**
- Ease-out for entering elements (start fast, end smooth)
- Ease-in for exiting elements (start smooth, accelerate out)
- Ease-in-out for transformations (smooth both ends)
- Bounce for playful/reward moments
- Linear for progress indicators

## Usage Guidelines

### When to Animate
✅ **Good uses:**
- Enhance understanding (show change/process)
- Provide feedback (user action response)
- Guide attention (direct user focus)
- Delight users (surprise and engagement)
- Reinforce brand (theme-appropriate motion)
- Support gamification (rewards, progress)

❌ **Avoid:**
- Animation for animation's sake
- Distracting from core content
- Slowing down critical paths
- Overwhelming users with motion
- Ignoring accessibility (motion sensitivities)

### Accessibility Considerations
- **Respect prefers-reduced-motion** settings
- Provide pause/stop controls for long animations
- Don't rely solely on animation to convey critical info
- Avoid rapid flashing or strobing
- Ensure sufficient contrast throughout animation
