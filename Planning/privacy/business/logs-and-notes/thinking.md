Optimal Modular Magnetic Block System
Core Principle: Standardized Edges with Alternating Polarity
┌─────────────────────────────────────┐
│         OPTIMAL DESIGN              │
│                                     │
│    N-S-N-S   (Top edge)            │
│  S ┌─────┐ N                       │
│  N │     │ S   Panel/Block         │
│  S │     │ N                       │
│  N └─────┘ S                       │
│    S-N-S-N   (Bottom edge)         │
│                                     │
└─────────────────────────────────────┘
1. Edge Strip Design (Best for Panels)
Magnetic strip layout per edge:
┌──┬──┬──┬──┬──┬──┐
│N │S │N │S │N │S │  ← Alternating polarity magnets
└──┴──┴──┴──┴──┴──┘
Why alternating polarity:
✅ Self-aligning (magnets find correct position)
✅ Prevents wrong-side attachment
✅ Distributes force evenly
✅ Works at any angle (90°, 180°, etc.)
