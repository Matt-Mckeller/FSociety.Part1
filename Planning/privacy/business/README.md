## What Is Shield4?

A **modular security enclosure** that protects password entry from observation attacks:
- Electromagnetic (WiFi CSI, radio signals)
- Thermal (infrared cameras)
- Acoustic (keyboard sounds)
- Visual (cameras, screens)

Basically: A personal SCIF that's affordable and apartment-friendly.
