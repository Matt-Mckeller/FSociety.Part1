## Windows 11 SHA-256 Verification

### Using PowerShell (Recommended)
```powershell
Get-FileHash C:\path\to\file.iso -Algorithm SHA256
```

### Using Command Prompt (certutil)
```cmd
certutil -hashfile C:\path\to\file.iso SHA256
```

Both commands output the SHA256 hash that you compare with the official checksum from the download source.
