📦 Installation: Full Disk Encryption

Configure During Install
⚠️ Must be done during installation!
Cannot be added after Ubuntu is installed.

Steps:

  • Boot from Ubuntu installation media
  • Choose "Erase disk and install Ubuntu"
  • ✅ Check "Encrypt the new Ubuntu installation"
  • ✅ Select "Use LVM"
  • Set strong encryption passphrase
Uses LUKS encryption - passphrase required at every boot

🔑 Install Yubikey Packages

Configure sudo apt update sudo apt install libpam-u2f yubikey-manager
Required for U2F authentication with your Yubikey 5C NFC

📝 Register Your Yubikey

Configure mkdir -p ~/.config/Yubico pamu2fcfg > ~/.config/Yubico/u2f_keys # Register backup Yubikey (recommended!) pamu2fcfg -n >> ~/.config/Yubico/u2f_keys
🔥 CRITICAL: Register a backup Yubikey! Without it, losing your primary key means losing access to your system.

🔐 Configure Login Authentication

Configure Test First! sudo nano /etc/pam.d/gdm-password

Add after @include common-auth:

auth required pam_u2f.so
⚠️ Keep a root terminal open!
Test in a new terminal before logging out. If it fails, you can revert the changes.

🛡️ Configure Sudo Authentication

Configure sudo nano /etc/pam.d/sudo

Add after @include common-auth:

auth required pam_u2f.so
Now every sudo command requires password + Yubikey touch

🔥 Enable Firewall (UFW)

Installed Enable sudo ufw enable sudo ufw default deny incoming sudo ufw default allow outgoing sudo ufw status verbose
UFW is installed by default but inactive. This enables it.

✅ Verify SSH is Disabled

Not Installed systemctl status ssh
Ubuntu Desktop does NOT install SSH server by default. No action needed!

🔄 Automatic Security Updates

Enabled by Default sudo apt install unattended-upgrades sudo dpkg-reconfigure -plow unattended-upgrades

Select "Yes" when prompted

Usually already enabled on Ubuntu Desktop

🛡️ AppArmor

Enabled by Default sudo aa-status
AppArmor (Mandatory Access Control) is active by default. No action needed!

🔒 Privacy & Screen Lock

Configure

Settings → Privacy:

  • Blank Screen Delay: 5 minutes
  • Automatic Screen Lock: ON
  • Lock Screen on Suspend: ON
  • Thunderbolt: User authorization only

🔐 BIOS/UEFI Secure Boot

Configure in BIOS

During system boot (F2/F12/DEL):

  • Enable Secure Boot
  • Set BIOS/UEFI password
  • Disable boot from USB/CD (or password protect)
Protects against boot-level malware and rootkits

🔑 Password Policy

Configure Optional sudo apt install libpam-pwquality sudo nano /etc/security/pwquality.conf

Recommended settings:

minlen = 14 dcredit = -1 ucredit = -1 ocredit = -1 lcredit = -1

💡 Optional: USB Guard

Advanced sudo apt install usbguard sudo usbguard generate-policy > /etc/usbguard/rules.conf sudo systemctl enable usbguard sudo systemctl start usbguard
Test carefully with your Yubikey! Can block unauthorized USB devices.
