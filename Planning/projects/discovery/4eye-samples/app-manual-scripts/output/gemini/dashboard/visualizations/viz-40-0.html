What is a Variable?

SVG_DIAGRAM very_high effectiveness
Visualization Description
The abstract concept of a variable as a named reference to a value in memory is made concrete and intuitive with a simple spatial diagram. This is the most standard and effective way to teach this fundamental concept.
Generation Prompt
Create a simple SVG diagram for beginners learning to code. On the left, draw a rectangle with the label 'Variable Name: userAge'. From this box, draw an arrow pointing to the right. The arrow should point to a second, slightly larger rectangle representing a memory location. Inside this second box, place the number '25' with the label 'Value'. Below the diagram, add the annotation: 'The variable 'userAge' is a name that points to the value 25 stored in memory.' Use friendly, clear fonts and a simple color scheme (e.g., blue for the variable, green for the value).
