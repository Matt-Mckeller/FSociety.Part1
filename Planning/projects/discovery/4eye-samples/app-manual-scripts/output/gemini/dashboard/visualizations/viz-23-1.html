Visualization Description
A flowchart effectively illustrates the process and sequence of how a memory is formed and stored, from initial sensory input to long-term storage. This helps students understand memory not just as a set of categories, but as a dynamic process.
Generation Prompt
Generate a vertical Mermaid flowchart for a psychology lesson. Start with a box labeled 'Sensory Input'. Draw an arrow to a box labeled 'Sensory Memory (Iconic/Echoic)' with an annotation 'Brief filter (<1 sec)'. From there, draw an arrow labeled 'Attention' to a box labeled 'Short-Term / Working Memory' with an annotation 'Active processing (~20 sec, 4 chunks)'. From the 'Long-Term Memory' box, draw an arrow labeled 'Retrieval' pointing back up towards the 'Short-Term / Working Memory' box. Use a clear, logical layout with standard flowchart shapes.
