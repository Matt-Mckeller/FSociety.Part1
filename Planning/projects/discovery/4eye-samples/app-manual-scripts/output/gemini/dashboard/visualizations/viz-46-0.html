Interactive Food Vocabulary Flashcards (English-Spanish)

FLASHCARD very_high effectiveness
Visualization Description
Flashcards are a proven and highly effective method for vocabulary acquisition. Adding images and interactivity creates a multi-sensory learning experience that strongly reinforces word association and recall.
Generation Prompt
Create a set of 6 interactive HTML flashcards for a beginner Spanish lesson. Each card should have a front and a back that flips on click. The front of each card must display a high-quality, clear image of the food item and the English word below it in a large, clean font (e.g., 'Apple'). The back of the card must display the Spanish translation in a bold font (e.g., 'Manzana'), along with its grammatical gender (la) and a simple phonetic pronunciation guide (mahn-SAH-nah). Use bright, engaging colors suitable for elementary/middle school students. The cards are: 1. Apple/Manzana (la), 2. Banana/Plátano (el), 3. Orange/Naranja (la), 4. Bread/Pan (el), 5. Milk/Leche (la), 6. Cheese/Queso (el).
