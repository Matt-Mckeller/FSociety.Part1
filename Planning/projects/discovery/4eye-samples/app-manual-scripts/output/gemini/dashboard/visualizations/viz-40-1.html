How a Variable is Assigned

ANIMATED_SVG high effectiveness
Visualization Description
Animation can demonstrate the process of variable assignment dynamically, which helps reinforce that it's an action. It shows the 'before' and 'after' state of memory.
Generation Prompt
Create a 3-step animated SVG for a 6th-grade audience. Step 1: Show a box labeled 'myScore' that is empty, with a question mark inside. Text below: '1. We declare a variable named myScore.' Step 2: Show the number '100' appearing on the side and moving towards the box. Text below: '2. We get a value (100).' Step 3: The number '100' enters the box, replacing the question mark. The box border flashes green once. Text below: '3. We assign the value to the variable.' The animation should be slow and clear, taking about 5 seconds in total.
