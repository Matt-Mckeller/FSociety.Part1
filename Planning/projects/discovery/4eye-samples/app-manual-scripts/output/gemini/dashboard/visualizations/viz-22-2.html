Visualizing Binary Search (O(log n))

ANIMATED_SVG high effectiveness
Visualization Description
Animating the process of binary search makes the concept of 'eliminating half the elements' concrete. It helps students understand why logarithmic time is so efficient in a way static text cannot.
Generation Prompt
Create an animated SVG diagram demonstrating a binary search for the number 42 in a sorted array of 16 elements [2, 5, ..., 42, ..., 98]. The animation should proceed in steps: 1. Show the full array. A pointer highlights the middle element (8th). 2. The number 42 is greater, so the entire left half of the array is grayed out and fades away. 3. The pointer moves to the middle of the remaining right half. 4. The number 42 is smaller, so the right half of this sub-array is grayed out and fades. 5. Repeat this process of halving and eliminating until the pointer lands on 42, which then flashes green. Include a step counter that increments from 1 to 4, showing that it only took 4 steps to find the element in a 16-element array (log2(16) = 4). The animation should be clear, slow-paced, and loopable.
