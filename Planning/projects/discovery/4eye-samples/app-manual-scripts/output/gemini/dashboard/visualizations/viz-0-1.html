Map of Major Nazi Camps and Ghettos in Europe

SPATIAL_DIAGRAM very_high effectiveness
Visualization Description
A map provides a stark visual representation of the geographic scale of the Holocaust, showing how it impacted communities across Europe. It makes the abstract numbers more concrete and geographically tangible.
Generation Prompt
Generate an interactive SVG map of Europe (circa 1942) for a 10th-grade history lesson. Plot the locations of major concentration camps (e.g., Dachau, Buchenwald) and extermination camps (e.g., Auschwitz-Birkenau, Treblinka). Use distinct, clear icons for each camp type. Also, shade the areas of major ghettos (e.g., Warsaw, Lodz). When a user hovers over a point, a tooltip should appear with the camp/ghetto name, its primary function, and estimated number of victims. The map must have a clear legend. Use a muted, respectful color scheme with high contrast for accessibility.
