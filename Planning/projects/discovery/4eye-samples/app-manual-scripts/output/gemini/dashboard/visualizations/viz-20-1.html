Timeline of Revolutionary Escalation (1773-1775)

TIMELINE high effectiveness
Visualization Description
A timeline provides essential chronological context, helping students understand the rapid pace of events. An interactive version allows for exploration of key terms and details without cluttering the main visual.
Generation Prompt
Generate an interactive HTML timeline for a high school audience covering the key events from 1773 to 1775. The timeline should be horizontal. Include the following key dates and events: Dec 1773 (Boston Tea Party), March-June 1774 (Intolerable Acts passed), Sep 1774 (First Continental Congress convenes), April 1775 (Lexington & Concord). Each point on the timeline should be a clickable circle. On hover, a tooltip should appear with a 1-2 sentence description of the event. For 'Intolerable Acts,' the tooltip should list the main components (Boston Port Act, etc.). Use a clean, modern design with a clear central line and legible fonts. British actions should be marked in red and colonial actions in blue.
