## 📋 How to Use This Log

**When to Add a Decision:**

- Architectural choices (patterns, structure)
- Technology selections (frameworks, libraries)
- Major trade-offs made
- Approach changes during implementation
- Any decision that affects multiple areas

**Format:**

- Use table format for easy scanning
- Include date, decision, rationale, alternatives
- Note who made the decision (if applicable)
- Reference related epic/feature
