## 🔄 Workflow Overview

### The Complete Process

```
1. START
   ├─ Create branch: feature/name
   ├─ Create plan: PLAN.md (if needed)
   └─ Share AI prompt from AI_WORKFLOW_PROMPT.md

2. DEVELOP
   ├─ Make small change
   ├─ Test change
   ├─ Commit with good message
   └─ Repeat

3. CHECKPOINT (after each phase)
   ├─ Commit: "Phase X Complete: summary + metrics"
   ├─ Update plan checklist
   └─ Document what was done

4. FINISH
   ├─ Final testing
   ├─ Update documentation
   ├─ Merge to main
   └─ Clean up branch
```

### Key Principles

1. **Branch for Everything** - Never commit directly to main
2. **Commit Frequently** - Small, logical, testable changes
3. **Test Before Commit** - Catch issues early
4. **Document as You Go** - Don't save for later
5. **Good Messages** - Future you will thank you

## 💡 Pro Tips from Experience

### From the Lottie Cleanup Project

**What Worked Really Well:**
1. Creating the plan document first
2. Committing after each logical change
3. Checkpoint commits after phases
4. Asking questions before starting
5. Breaking large refactors into phases

**What We Learned:**
1. Good messages save SO much time later
2. Small commits are easier to review/revert
3. Documentation prevents repeated questions
4. Testing after each phase catches issues early
5. Checklists are satisfying and keep you on track

**Time Saved:**
- Found issues immediately (not days later)
- Never wondered "what broke?"
- Could confidently continue next session
- Had clear rollback points
- Documentation was done (not pending)

## 🔧 Customization

### Adapting for Your Needs

**These are guidelines, not laws.** Adapt as needed:

- **Solo project?** Can be more relaxed with branches
- **Team project?** Stricter PR reviews needed
- **Experimenting?** Create `experiment/` branches
- **Hotfix?** Can commit directly to main (document why)
- **Large feature?** Break into sub-branches

**But always:**
- Write good commit messages
- Test before committing
- Document significant changes
- Keep commits logical and focused
