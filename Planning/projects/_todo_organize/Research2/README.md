## How to Use These Prompts

### With AI Research Tools

1. **Copy the entire prompt content** from any `.md` file
2. **Paste into your AI research tool** (Claude, GPT-4, etc.)
3. **Set a 2-hour time limit** for comprehensive research
4. **Request the structured output format** as specified in each prompt

### Expected Output Format

Each research session will produce:

#### 1. Executive Summary (1-3 min read)

- Top 3 recommendations with use cases
- BUILD vs BUY vs DOWNLOAD decision
- Key reasoning in 2-3 sentences

#### 2. Detailed Overview (5-10 min read)

- Solution comparison tables
- Feature matrices
- Quality assessments
- Use case mappings
- Integration considerations

#### 3. Comprehensive Documentation

- Individual solution deep-dives
- Code quality analysis (open source)
- Setup guides and tutorials
- Architecture patterns
- Migration considerations
- Next steps and resources

#### 4. Visual Deliverables

- Markdown comparison tables
- Mermaid diagrams for decision trees
- ASCII charts where appropriate
- Links to demos and documentation

### Research Quality Gates

Each prompt includes minimum requirements:

- **Open Source Solutions**: At least 5 fully usable projects
- **Paid Solutions**: At least 3 commercial options with pricing
- **Quality Assessment**: Code quality, user base, maintenance status
- **Integration Analysis**: Setup complexity, documentation quality
- **Decision Framework**: Clear criteria for BUILD vs BUY vs DOWNLOAD

### Success Criteria

After using any prompt, you should be able to answer:

- Should I build this myself?
- What's the best open source starting point?
- What paid tools are worth considering?
- What's the path of least resistance to production?

## Research Parameters

- **Max Duration**: 2 hours per topic
- **Depth**: Comprehensive - prioritize information quality over speed
- **Scope**: Both open source (fully usable) and paid solutions
- **Focus**: Production-ready tools with active communities

## Technology Context

While these prompts are technology-agnostic, they're optimized for:

- **Primary Stack**: JavaScript/TypeScript/Node.js
- **Secondary**: Python, Go, Rust (when appropriate)
- **Deployment**: Self-hosted, cloud, and hybrid options
- **Integration**: API-first, modular architectures preferred
