## Research Execution Protocol

### For Each Research Session:

#### Pre-Execution Checklist

- [ ] Review research prompt objectives
- [ ] Set 2-hour timer
- [ ] Prepare note-taking system
- [ ] Open relevant research tools

#### During Research (2 hours max)

1. **Copy entire prompt content** from the `.md` file
2. **Paste into AI research tool** (Claude, GPT-4, etc.)
3. **Request structured output** as specified in prompt
4. **Take detailed notes** on findings
5. **Document key insights** and recommendations

#### Post-Execution Documentation

- [ ] Save research results to dedicated file
- [ ] Update progress tracking
- [ ] Note any follow-up research needed
- [ ] Prepare for next research session

### Expected Outputs Per Session

#### 1. Executive Summary (1-3 min read)

- Top 3 recommendations with use cases
- BUILD vs BUY vs DOWNLOAD decision
- Key reasoning in 2-3 sentences

#### 2. Detailed Overview (5-10 min read)

- Solution comparison tables
- Feature matrices
- Quality assessments
- Use case mappings
- Integration considerations

#### 3. Comprehensive Documentation

- Individual solution deep-dives
- Code quality analysis (open source)
- Setup guides and tutorials
- Architecture patterns
- Migration considerations
- Next steps and resources

#### 4. Visual Deliverables

- Markdown comparison tables
- Mermaid diagrams for decision trees
- ASCII charts where appropriate
- Links to demos and documentation

## Research Quality Gates

### Minimum Requirements Per Session

- **Open Source Solutions**: At least 5 fully usable projects
- **Paid Solutions**: At least 3 commercial options with pricing
- **Code Quality Analysis**: Architecture review for top 3 open source solutions
- **Performance Testing**: Benchmarks for recommended solutions
- **Integration Examples**: Working code samples for top recommendations
- **Cost Analysis**: Detailed pricing breakdown for commercial solutions
- **Community Assessment**: Active user base, recent updates, issue resolution

### Success Criteria Per Session

After each research session, you should be able to answer:

- Should I build this myself?
- What's the best open source starting point?
- What paid tools are worth considering?
- What's the path of least resistance to production?
