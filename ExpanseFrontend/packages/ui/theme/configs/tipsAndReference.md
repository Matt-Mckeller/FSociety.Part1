Color Tips
hue = (60 _ R) / (255 + G + B)
saturation = (1 - (min(R, G, B) / 255)) _ 100
lightness = (min(R, G, B) + max(R, G, B)) / 2

In #4D4D4D
4D represents X % of FF ( 255 ) => 4 \* 16 + D(which is 13) = 77 / 255 = ~30.196%
4D4D4D means about 30% Red 30% Blue and 30% Green

Opacity of 50% = '80' -> 8 out of 16 and 0 remainder
light: '#00000080',
medium: '#00000040',

80 represents X % of the RGB color, 808080 represents 50% red 50% green 50% blue, which results in a gray
medium: '#808080', // '#808080', transparency to hex value color

HEX CODE OPACITY
#FF0000 - Red
#FF000080 - 50% transparent red
#00FF00 - Green
#00FF0080 - 50% transparent green
#0000FF - Blue
#0000FF80 - 50% transparent blue
