# Quick Wins Guide Components

This folder contains Storybook stories for the Quick Wins Guide feature in the 4eye application.

## Components

### Section
A section wrapper component with scroll-triggered fade-in animation and consistent styling.

### AccordionItem
A styled accordion for expandable content with checkmark prefix and blue accent border.

### OverviewCards
A grid of cards displaying key purposes and outcomes with hover lift animation.

### Quiz
Interactive stepper-based quiz with multiple choice questions, scoring, and reset.

### MermaidChart
Renders Mermaid flowcharts and diagrams (shows placeholder in Storybook).

### ChatAssistant
AI-powered chat drawer with floating button, suggested questions, and message threading.

## Usage in 4eye App

These components are located at:
```
apps/4eye/src/modules/quick-wins-guide/components/
```

The Quick Wins Guide page is accessible at:
```
/quick-wins-guide
```
