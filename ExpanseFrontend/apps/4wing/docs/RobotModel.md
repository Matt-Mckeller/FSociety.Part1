# Robot Model

## Purpose
Friendly medium for camera/mic—reduces discomfort of being recorded during counseling sessions.

**Important: The robot is passive. It never speaks or interrupts sessions.**

## Core Functions
| Function | Description |
|----------|-------------|
| Audio Recording | Primary input for transcription |
| Video Recording | Optional, for nonverbal analysis (P2) |
| Status Indicators | Lights show: recording, processing, idle |
| Brand Presence | Ice-breaker, approachable companion |

**What the robot does NOT do:**
- Does not speak or make sounds
- Does not interrupt sessions
- Does not provide feedback directly to client

## Design Requirements
- **Aesthetic**: Personable creature/character (not humanoid)
- **Demeanor**: Non-threatening, approachable, calming
- **Size**: Compact, desk-friendly (fits on counselor's desk)
- **Presence**: Visible but unobtrusive

## Hardware Specifications
| Component | Requirement |
|-----------|-------------|
| Microphone | Omnidirectional, noise-canceling |
| Camera | 1080p wide-angle (optional) |
| Lights | RGB LED for status indication |
| Connectivity | WiFi / Bluetooth to app |
| Power | USB-C or rechargeable battery |

## Status Light Meanings
| Color | State |
|-------|-------|
| 🟢 Green | Idle, ready |
| 🔵 Blue | Recording/listening |
| 🟡 Yellow | Processing |
| 🔴 Red | Error / needs attention |
| ⚪ Off | Powered off / privacy mode |

## Design Inspiration
- Approachable like a therapy comfort object
- Not distracting during emotional moments
- Familiar enough to feel safe, novel enough to be memorable
