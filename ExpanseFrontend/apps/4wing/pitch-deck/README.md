# Pitch Deck - Counsellor Support

An interactive pitch deck presentation built with React, Next.js, MUI, and SwiperJS.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3002](http://localhost:3002) in your browser.

## Navigation

- **Arrow Keys**: Navigate between slides
- **Mouse Wheel**: Scroll through slides
- **Click**: Use navigation arrows or pagination dots
- **F**: Toggle fullscreen (via button)
