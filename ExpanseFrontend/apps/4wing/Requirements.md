## Vision
Heal people. Improve mental health. Enable growth. Improve learning.

## Concept
AI app + companion robot that supports mental health through three modes:
1. Assists counselors during live sessions (robot captures silently; AI assists via screen)
2. Supports clients between counseling sessions
3. Provides standalone AI companionship for independent users

---

## Product Modes

| Mode | User | Description |
|------|------|-------------|
| **In-Person** | Counselor | Robot captures session; AI assists via screen (silent) |
| **At-Home (Connected)** | Client | Support between sessions with a real counselor |
| **At-Home (Independent)** | Individual | Standalone AI companion, no counselor required |

### In-Person Mode
For counselors during live sessions with clients. Robot is passive—never speaks or interrupts.
- Robot captures audio/video silently
- AI assists counselor via app screen only
- Live transcription with speaker labels
- Real-time alerts (escalation, missed cues)
- AI response suggestions (on screen)
- Session summaries generated post-session

### At-Home (Connected) Mode
For clients who attend real counseling sessions. Used between appointments.
- AI companion chat (conversational support)
- Session recaps from counselor
- Homework tracking and reminders
- Daily mood check-ins (shared with counselor)
- Coping tools (breathing, grounding)
- Crisis resources

### At-Home (Independent) Mode
For individuals without a counselor. Standalone AI mental health companion.
- AI companion chat (primary feature)
- Self-guided mood check-ins
- Reflection journal
- Coping tools (breathing, grounding)
- Crisis resources
- No counselor integration
