Architecture & Technology

Technical foundation powering the PresentationApp platform.

Technology Stack

AspectDetail
FrontendReact, MUI, Next.js
BackendNestJS with TypeORM (PostgreSQL)
Authentication@nestjs/passport (JWT)
Real-TimeWebSockets (NestJS Gateway) for presenter mode sync and live collaboration
State ManagementRedux with backend persistence
AI IntegrationBackend API routes proxying to AI services (OpenAI/Gemini/Claude)
Content StorageCustom block-based content system with layered variants
RoutingURL-addressable slides (e.g., /presentation/:presentationId/slide/:slideId)
InternationalizationMulti-tier: react-i18next for UI + database content translations + AI-assisted fallback
Component LibraryStorybook for all components
Design PhilosophyVery modular and highly reusable

Content System

A custom block-based content storage system enabling reusable content, layered variants, and AI transformation caching.

Block Types
TextBlock

Rich text with markdown support

CodeBlock

Syntax-highlighted code with optional execution

QuizBlock

Inline quiz with question/answers

MediaBlock

Image, video, SVG, Lottie animation

InteractiveBlock

Custom interactive component (why chip, expandable, etc.)

AITransformBlock

Cached AI-generated content variant

Content Layering
Base Content Layer (default)
  └── Audience Layer (student/teacher/parent overrides)
       └── Accessibility Layer (ADHD/autism/dyslexia variants)
            └── Language Layer (i18n translations)
                 └── AI Cache Layer (cached AI transformations)
Content API
GET /api/content/:blockId?variant=adhd&locale=es&audience=student

Returns merged content with all applicable layers applied.
