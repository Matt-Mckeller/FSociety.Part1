🎯 Core Features
Fixed Screen Position

Entire app maintains a static shell layout; only primary content scrolls optionally per slide

Progress Tracking

Slide-based checkmarks + percentage-based overall completion displayed in navigation

Polished Transitions

Slides have animated transitions and optimized UX for smooth presentation flow

Configurable Audiences

Slides can be targeted to specific audience types and included in multiple presentations

👁️ Viewing Modes
Presenter Mode
Primary

Presenter controls slide progression for the audience in real time via WebSocket. All audience views are synced to the presenter's current slide automatically.

Real-time sync
Audience reactions
Pacing control
Self-Paced Learner Mode

User navigates freely at their own pace. The presenter chat appears as a passive overlay, allowing independent exploration while staying connected.

Free navigation
Chat overlay

👥 Audience Types

Content can be tailored for different audience types. Each slide can be targeted to one or more audiences.

TypeDescription

👁️General ViewerPublic / general audience

📋 Slide Registry

Slides exist in a reusable registry. Each slide can belong to multiple presentations and target specific audiences.

{
  id: "slide-finance-overview",
  name: "Finance Overview",
  presentationIds: ["investor", "founders", "advisors"],
  audienceTypes: ["employee", "administration"],
  order: 3,
  unlockLevel: 2
}
