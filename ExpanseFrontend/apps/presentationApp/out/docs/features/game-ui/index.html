🎮 Game Mechanics

⭐

XP (Experience Points)

Earned from viewing slides, using actions, completing quizzes

🪙

Coins

Currency spent on AI actions; earned from quests and achievements

📈

Levels

Progression system based on XP; unlocks content and features

🎯

Quests

Trackable objectives with XP/coin rewards

🏆

Achievements

Milestone recognitions for accomplishments

🎒

Inventory

Items owned, equipped cosmetics, unlocked rewards
