Action Bars

Game-style action bars for slide-by-slide content interaction

Module & Architecture
AI Actions
Game System
Assumed React Context:
ActionBarContext
ActionCooldownContext
AIActionsContext
Note: Context structure is assumed and may not be complete.

Inspired by action bars from games like League of Legends, World of Warcraft, and Fortnite — bringing familiar gaming UI patterns to educational content interaction.

Key Features
Toggleable

Activate bars from layout icons — switch between different action sets based on context

Cooldowns

Actions have cooldown timers to encourage thoughtful usage and prevent spam

Resource Costs

Each action consumes resources (XP, coins, energy) creating meaningful choices

Custom Click Actions

Context-aware popup FABs appear with relevant actions based on what is clicked
