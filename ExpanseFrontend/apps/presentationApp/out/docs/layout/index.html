Application Layout

The presentation app uses a fixed shell layout with a left navigation panel, central content area, and right-side contextual panels. The top bar provides user status and a consolidated profile menu.

Quick Access Panels
Quick Access Buttons: Located at the bottom of the left navigation, these buttons toggle contextual panels that slide in from the right. This keeps important tools readily accessible while maintaining a clean content area.
Panel Behaviors & Priority:
  • Overlay panels (Quest): Opens with a backdrop, grays out content, becomes primary focus. Content does not resize.
  • Bottom panel (Chat): Opens from bottom, takes full width priority. Content shrinks vertically. When Notes is also open, Notes sits above Chat.
  • Right side panels (Notes): Opens from right, content shrinks horizontally. Height adjusts when Chat is open.
Priority Order: Quest (overlay) > Chat (bottom) > Notes (right) > Content

Design Principles
🎯 Fixed UI Shell

The entire app maintains a fixed viewport; only the primary content area scrolls. This maintains persistent access to navigation and game UI elements.

📐 Contextual Panels

Right-side panels slide in on demand, providing quick access to quests, chat, and notes without leaving the current content. Only one panel open at a time.

🖱️ Quick Access

Important action buttons (Quests, Chat, Notes) are positioned at the bottom of the left navigation for easy reach, keeping them visible throughout the session.

👤 Unified Profile

Profile, Inventory, and Settings are consolidated under the avatar dropdown menu, reducing top-bar clutter while maintaining accessibility.
