Data Models

Core entities stored in the backend. Detailed schemas in TypeScript interfaces.

User & Game State
EntityKey FieldsDescription
Userid, email, displayName, level, xp, coins, preferences, equippedItemsPlayer profile and game state
UserQuestProgressuserId, questId, progress, isComplete, completedAtUser's progress on each quest
InventoryuserId, items[]User's owned items and unlocks
Presentations & Slides
EntityKey FieldsDescription
Slideid, name, presentationIds[], audienceTypes[], order, unlockLevelSlide metadata with audience targeting
SlideBlockslideId, blockId, order, overridesBlock instance in a slide (with optional local overrides)
Presentationid, name, description, slideIds[], isPublicCollection of slides forming a presentation
PresentationSessionid, presenterId, presentationId, currentSlideId, participants[], isLiveReal-time presenter session for sync
Content System
EntityKey FieldsDescription
ContentBlockid, type, baseContent, version, createdAt, updatedAtReusable content block
ContentVariantblockId, variantType, locale, audienceType, content, isAIGenerated, reviewedAtLayered variant (audience, accessibility, language)
ContentVersionblockId, version, content, status, publishedAt, publishedByVersion history with draft/review/published workflow
AIContentCacheblockId, action, params, result, generatedAt, hitCountCached AI transformations
TranslationStatusblockId, locale, status, translator, reviewedByTranslation workflow tracking
Quests & Feedback
EntityKey FieldsDescription
Questid, name, description, criteria, rewardXp, rewardCoins, isRepeatableTrackable objectives with rewards
Feedbackid, userId?, sourceType, sourceId, type, content, rating, createdAtUser or AI feedback on content
