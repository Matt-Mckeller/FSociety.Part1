# PresentationApp Documentation Wiki

Documentation wiki for the Expanse learning/presentation platform.

Converts requirements from `PresentationApp.md` into browsable wiki pages.

## Development

```bash
npm install
npm run dev
```

Opens at http://localhost:3100

## Structure

```
src/
  app/           # Next.js App Router pages
    docs/        # Documentation wiki routes
  components/    # Wiki UI components
  types/         # TypeScript data models
  docs/          # MDX/content files
```
