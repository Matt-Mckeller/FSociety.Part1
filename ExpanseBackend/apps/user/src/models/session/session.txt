
Your task is to create a session model class in javascript named Session
    # Imports and Exports
    Prefer import and export statements rather than require or export.modules
    Include both an export default and named export for the session class
        For Example: 
            export default Model;
            export { Model };

    # Databases
    The model will use mysql2 for reading and writing to the database
    The database name used for this model is expanse_auth
    The database table used for this model is sessions
    The model should accept a connection object in the constructor which is a mysql2 connection object. 
    Use this connection object for performing database read and writes.
    This connection object is created using mysql2/promise 
    Use the this.connection.execute function for performing queries

    # Constructor
        Define variables in the constructor like
        constructor(connection) {
            this.connection = connection;
            this.id = null;
            this.string = '';
            this.boolean = false;
            this.number = null;
        }

    # Variable definitions
    Default string variables to empty quotes
    Default number variables to null
    Default booleans to null
    Default arrays to be empty arrays

    import { AuthConfig } from '../config.js';

    The model should have the following fields: 
    id: number
    userId: number
    jwt: string
    ipAddress: string
    userAgent: string
    createdAt: string | datetime
    updatedAt: string | datetime

    The model should contain the following functions
    // Function: createJwt
        This function creates a jwt from an object named jwtData passed in through paramters 
        This function references the secretKey for creating the JWT from AuthConfig.jwtSecretKey
        This function utilizes the jwt library from 'jsonwebtoken'
        This function creates a jwt that expires in 3 days
        This function updates the models jwt property with the created jwt after creating it
        This function returns the created jwtToken.

    // Function: save
        This function saves the properties of the model to the database using the connection object.
        Updates the models id after successful insertion
        Returns the id from the successful insertion
        Do not save the createdAt or updatedAt fields to the database. They are inserted automatically by sql
