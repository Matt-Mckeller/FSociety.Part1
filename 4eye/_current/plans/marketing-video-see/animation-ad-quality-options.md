# Animation & Ad Quality — Options & Recommendations

> **Companion to** [`marketing-video-see.md`](./marketing-video-see.md) and [`project-website-4eye.md`](../project-website-4eye.md).
> **Pipeline:** [`gallery-app`](./gallery-app/README.md) (Gemini gen → Veo/Runway animate → sequences → final cut).
> **Created:** 2026-05-30

## North Star

**Heighten engagement by increasing understanding.** Every option below is judged on whether it makes a viewer (a) *feel* the product (excitement/emotion), (b) *picture* using it (product visualization), (c) *retain* a core concept or data point, and (d) move toward sign-up.

- **Audience this pass:** Teachers/classrooms **&** students first. (Individual/life = a *second* video appended or split out — design Scene 1 so it forks cleanly.)
- **Single promise to protect:** *Gamification of Learning. Learn More, Earn More, Enjoy More.*
- **Constraint:** none — be ambitious, but focus on **one video, one length** first; don't fan out into a cut family yet.

**Scoring key used below:** 🎯 Conversion · 💡 Understanding · ⚡ Excitement · 🔁 Reuse/cost. Each option is rated **Impact (1–5) / Effort (S/M/L)**.

# Part A — The Marketing Video (rank #1)

> **What this is:** the Scene 1 *Classroom of Tomorrow* film generated by the [gallery-app](./gallery-app/README.md), described in [`marketing-video-see.md`](./marketing-video-see.md). **One video, one length** for now. Not a separate asset.

Three layers to improve: **craft (motion quality)**, **structure (story/pacing)**, and **teaching (how concepts land)**.

## A1. Craft — make the motion read as premium, not "AI slideshow"

| # | Option | Why it raises understanding/excitement | Rate |
|---|--------|-----------------------------------------|------|
| A1.1 | **Stay on Veo, single image → video, and *describe the end state* in the prompt.** Veo's dual-frame (start+end) path isn't supported (see [test log](./gallery-app/docs/video-gen-test-log.md)); the working pattern is one start frame + a prompt that spells out exactly where the motion lands. Invest in **precise motion prompts** (what moves, how far, what's static, where it ends) rather than switching providers. | Tight end-state prompts = the viewer's eye follows *intent*, not noise. | **5 / M** |
| A1.2 | **Author the end state in the prompt, not a second image.** For a beat with a specific transformation, lock a clean start frame and write the destination into the prompt (pose, HUD state, score, expression). Use it where the *meaning* of the beat matters; let free/ambient motion ride looser prompts elsewhere. | You author the meaning of the beat instead of hoping the model guesses it — without leaving Veo. | **4 / M** |
| A1.3 | **Add a deliberate camera grammar.** Reserve push-ins for power-ups/reveals, holds for data points, whip/Lens cuts for scene changes. Document it as a rule per beat in the animate seed. | Consistent camera language = subconscious "this is a real product film." | **4 / S** |
| A1.4 | **Motion-curve pass on on-screen UI** (HUD appearing, Zap, coins). Ease-in/overshoot/settle, never linear. Mirror the *exact* app/Storybook easing so the ad matches the real product. | Product-accurate motion = trust + "I can picture using this." | **4 / M** |
| A1.5 | **Sound + emotional arc, designed first.** Don't aim for generic "pleasant" — build a deliberate arc: **tension/anger → intensity/battle → release/excitement → satisfaction.** Lock a music bed that follows that curve + signature SFX (spell cast, coin, level-up, Lens whoosh) and cut picture to it. | The emotional swing (not the frames) is what makes it exciting and memorable. | **5 / M** |
| A1.6 | **Grade + grain + consistent LUT** across all frames in post so anime/futuristic shots from different gen runs feel like one film. | Removes the #1 tell of stitched-AI output. | **3 / S** |

# Do-First Shortlist (highest leverage / lowest regret)

1. **A2.1 + B1** — Cold-open hook as slide-1 autoplay loop. *Biggest conversion lever, smallest effort.*
2. **A3.2** — Lock the 4 HUD symbols everywhere. *Cheap, compounding clarity.*
3. **A1.1 / A1.2** — Veo single image → video with the end state written into the prompt. *Reliable motion where it matters, no provider switch.*
4. **A2.3** — Multi-metric before/after data climax (engagement + wellbeing + learning rolling into Total Score). *The proof moment.*
5. **A3.7** — Anxiety-calming Heal beat in the intro. *Shows the product caring — high emotional payoff.*
6. **A1.5** — Lock the emotional audio arc (tension → intensity → release → satisfaction) early. *Carries the whole film.*
