# References

Drop visual references here. Organize by purpose.

## Folders

- `inspiration/` — stills, frames, mood references collected from existing work you want to reference
  - Suggested subfolders: `inspiration/scene-1-classroom/`, `inspiration/scene-2-coffee-shop/`, `inspiration/scene-3-sea/`, `inspiration/lens-transitions/`, `inspiration/hud-treatments/`
- `style-tests/` — your own 5s style test outputs before scaling production
  - Suggested subfolders: `style-tests/veo3/`, `style-tests/sora2/`, `style-tests/kling/`, `style-tests/runway/`

## Adding references

When you save an inspiration image, also add a 1-line note in the relevant scene file or in `00-style-bible.md` § 8 about *what specifically you're stealing* from it. Otherwise the reference gets lost.
