## Two Layout Paradigms

| Paradigm | Navigation | Chrome | Best For |
|----------|------------|--------|----------|
| **Basic Web Layout** | URL routes | ContentFrame (pushes content) | Documentation, dashboards |
| **Spatial Layout** | MapGridNavigation (x,y) | HUD (floats over content) | Real-time interfaces, games |

> **Why HUD for real-time?** The HUD keeps controls floating over content without layout shifts—ideal for live dashboards, monitoring, collaborative editing, and gaming where continuous visual attention is critical.

## Core Modules

| Module | Location | Purpose |
|--------|----------|---------|
| Navigation | `spatial/map/` | MapGridNavigation for spatial |
| ContentFrame | `core/content-frame/` | Structural shell for web layouts |
| HUD | `spatial/overlays/` | Floating overlay for spatial |
| Components | `hud-components/` | Shared UI elements |

---

## Key Patterns

**Floating > Pushing**: HUD floats via fixed positioning, content fills viewport  
**Presets > Manual Config**: HudPreset bundles component visibility  
**Context > Props**: HeaderContextProvider manages header state
