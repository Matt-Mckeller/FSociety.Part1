# @expanse/shell

**Layout primitives and utilities for building spatial and traditional web interfaces.**

---

## Overview

`@expanse/shell` provides two layout paradigms:

- **Spatial Layout** - Full-viewport, MapGridNavigation-based, HUD overlay system
- **Basic Web Layout** - Traditional header/nav/footer, URL-based routing

Perfect for:

- **Immersive Applications** - Navigate spatial content with arrow keys, minimap
- **Dashboard Applications** - Traditional admin panels and tools
- **Portfolio Sites** - Create engaging spatial navigation experiences
- **Game-like UIs** - Grid-based movement and exploration
- **Accessibility-First Apps** - Keyboard-first navigation

## Quick Start

### Installation

```bash
# In your app's package.json peerDependencies
pnpm add @expanse/shell
```

### Basic Usage

```tsx
import { NavigationProvider, MinimalLayout } from '@expanse/shell';

const gridConfig = {
  dimensions: {
    width: 5,
    height: 5,
    homePosition: { x: 2, y: 2 },
    wrapAround: true,
  },
  tiles: [
    {
      id: 'home',
      position: { x: 2, y: 2 },
      url: '/',
      seo: { title: 'Home' },
      display: { label: 'Home', colors: { inactive: '#ccc', active: '#00f' } },
    },
    // ...more tiles
  ],
};

const pageRegistry = {
  home: () => <div>Welcome Home!</div>,
  about: () => <div>About Page</div>,
};

function App() {
  return (
    <NavigationProvider config={gridConfig}>
      <MinimalLayout preset="floating-controls" autoPages={pageRegistry} />
    </NavigationProvider>
  );
}
```

### What This Does

1. **Creates a 5×5 grid** with home at center (2,2)
2. **Enables keyboard navigation** - Arrow keys move between tiles
3. **Renders pages automatically** - Based on current grid position
4. **Shows floating controls** - NavigationPad + Minimap
5. **Handles routing** - Syncs URL with grid position

## Core Concepts

### Navigation Provider

Wraps your app and provides navigation state to all children:

```tsx
<NavigationProvider config={gridConfig}>
  {/* Your app */}
</NavigationProvider>
```

### Grid Configuration

Defines the navigation grid structure:

```tsx
interface MapGridNavigationConfig {
  dimensions: {
    width: number;        // Grid width
    height: number;       // Grid height
    homePosition: { x: number; y: number };  // Starting position
    wrapAround?: boolean; // Enable edge wrapping
  };
  tiles: TileConfig[];    // Tile definitions
}
```

### Tiles

Individual grid positions with associated pages:

```tsx
interface TileConfig {
  id: string;             // Unique identifier
  position: { x: number; y: number };  // Grid coordinates
  url?: string;           // Optional URL for routing
  seo: {                  // SEO metadata
    title: string;
    description?: string;
  };
  display: {              // Visual properties
    label: string;
    colors: {
      inactive: string;   // Default color
      active: string;     // Active/hover color
    };
  };
}
```

## Navigation Patterns

### Arrow Key Navigation

```tsx
// Built-in keyboard support
←  Move left
→  Move right
↑  Move up
↓  Move down
Home  Jump to home position
Backspace  Go back in history
```

### WASD Navigation

```tsx
// Alternative keyboard layout
W  Move up
A  Move left
S  Move down
D  Move right
```

### Programmatic Navigation

```tsx
import { useNavigation } from '@expanse/shell';

function MyComponent() {
  const { moveTo, moveUp, moveDown, moveLeft, moveRight } = useNavigation();
  
  // Jump to specific position
  moveTo({ x: 3, y: 2 });
  
  // Move in direction
  moveUp();
  moveRight();
}
```

## Layout Templates

Pre-built layouts for common use cases:

### MinimalLayout (Recommended)

Lightweight layout with 6 presets:

```tsx
<MinimalLayout 
  preset="floating-controls"  // or "full-screen", "overlay", "persistent"
  autoPages={pageRegistry}
/>
```

**Presets:**
- `full-screen` - Full-screen content, controls hidden
- `full-screen-compact` - Full-screen with compact controls
- `overlay` - Overlay controls, auto-hide
- `overlay-compact` - Compact overlay controls
- `persistent` - Always-visible controls
- `persistent-compact` - Compact always-visible

### FullScreenLayout

Dedicated full-screen experiences:

```tsx
<FullScreenLayout autoPages={pageRegistry} />
```

### DashboardLayout

Dashboard with sidebars and panels:

```tsx
<DashboardLayout 
  autoPages={pageRegistry}
  showSidebar={true}
/>
```

## Routing Integration

### Next.js App Router

```tsx
'use client';
import { useRouter, usePathname } from 'next/navigation';
import { NavigationProvider } from '@expanse/shell';

function AppNavigation({ children }) {
  const router = useRouter();
  const pathname = usePathname();
  
  return (
    <NavigationProvider 
      config={gridConfig}
      onTileChange={(tile) => {
        if (tile.url) router.push(tile.url);
      }}
    >
      {children}
    </NavigationProvider>
  );
}
```

### React Router

```tsx
import { useNavigate, useLocation } from 'react-router-dom';

function App() {
  const navigate = useNavigate();
  
  return (
    <NavigationProvider 
      config={gridConfig}
      onTileChange={(tile) => {
        if (tile.url) navigate(tile.url);
      }}
    >
      <MinimalLayout />
    </NavigationProvider>
  );
}
```
